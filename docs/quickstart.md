# 快速开始

目标：把一个窗口化运行的视觉小说/2D 游戏放大到全屏，并确认输入、暂停、停止都正常。

## 1. 启动

```bash
./GemPrismUpscaler
```

第一次使用建议先运行一次环境检查：

```bash
./GemPrismUpscaler --doctor
```

## 2. 选择输出显示器和算法

在“超分”页：

- **超分算法**：先用默认的 `Anime4K S`。想对比效果可换 `Anime4K M/L`，或 `双线性`。
- **输出显示器**：选择游戏所在的那块屏；一般保持“自动”即可。
- **启动方式**：保持默认的“嵌套启动”。

## 3. 嵌套启动游戏

1. 先完全退出 Lutris（包括托盘）。
2. 在“嵌套启动命令”里填入启动命令，例如：

   ```text
   env LUTRIS_SKIP_INIT=1 lutris lutris:rungameid/<id>
   ```

   `3` 是 Lutris 里的游戏 id；可以在 Lutris 里查看，或运行
   `lutris --list-games`。
3. 点“开始超分”。

程序会创建一个私有虚拟桌面，在其中启动命令，然后把游戏窗口放大到全屏。

## 4. 操作

| 操作 | 效果 |
|---|---|
| **暂停超分** | 嵌套模式下切回游戏原窗口；再点“继续超分”切回放大画面 |
| **停止超分** | 结束本次会话；嵌套模式下会结束由本次命令启动的游戏/启动器 |
| **`Alt+Shift+A`** | 显示/隐藏超分画面 |
| **关闭游戏窗口** | 会话正常结束，界面显示“游戏已退出” |

“暂停”只是切换显示，不会杀进程；“停止”才会结束会话。

## 5. 已有游戏窗口

如果游戏已经在运行：

1. “启动方式”选“已有游戏窗口”。
2. 窗口类型选“X11 窗口”，在列表里点选游戏窗口；或选“Wayland 全屏窗口”，按提示选择。
3. 点“开始超分”。

X11/XWayland 窗口可以窗口化；原生 Wayland **只支持全屏窗口**，因为该路径不转发输入，需要让鼠标直接穿透到下方游戏。
