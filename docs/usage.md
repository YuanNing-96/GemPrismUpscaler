# 使用说明

## 1. 界面结构

主窗口左侧只有三个页签：

- **超分**：选择算法、输出显示器和启动方式，开始/暂停/停止会话。
- **设置**：重复打开行为、关闭行为、托盘、刷新间隔、日志位置。
- **日志**：查看本次运行日志，打开日志目录，导出诊断包。

窗口底部没有“退出”按钮。关闭主窗口即退出（或按设置里的“最小化到托盘”收进托盘）；托盘菜单里的“退出”也会结束程序。

## 2. 超分页

### 2.1 通用选项

| 选项 | 说明 |
|---|---|
| 超分算法 | `Anime4K S`（默认）、`M`、`L`、`VL`，以及 `双线性`。 |
| 输出显示器 | 超分画面落在哪块屏。默认跟随游戏窗口/自动选择；嵌套启动时以所选屏幕的物理分辨率和刷新率为准。 |
| 启动方式 | **嵌套启动**（默认）或**已有游戏窗口**。 |

算法都是 2× 超分后再用 Lanczos-2 映射到输出分辨率：

- `Anime4K S`：速度和效果均衡，日常推荐。
- `Anime4K M/L`：更高的 CNN 档位，GPU 开销更大。
- `Anime4K VL`：实验性最高画质档，18 个 pass，显存和首帧开销明显更高；帧率不作为保证。
- `双线性`：最快的回退/对比档。

### 2.2 嵌套启动（推荐）

适合窗口化运行的视觉小说和 2D 游戏。

1. 先完全退出 Lutris（包括托盘图标）。
2. 在命令框里填启动命令，例如：

   ```text
   env LUTRIS_SKIP_INIT=1 lutris lutris:rungameid/<id>
   ```

3. 点“开始超分”。

命令按参数直接启动，**不经过 shell**。因此：

- 路径里有空格时自己加引号；
- `;`、`&&`、通配符、变量展开不会生效；
- 确实需要 shell 特性时，显式使用 `bash -lc '...'` 并正确加引号。

运行后：

- 游戏和它的对话框会显示在独立的宿主窗口中；
- 鼠标、键盘、滚轮转发到游戏；
- 游戏窗口尽量保持窗口化/无边框窗口，不要切独占全屏；
- 关闭游戏窗口会结束会话；点“停止超分”会结束由本次命令启动的进程树。

> **Lutris 注意**：v1.0 不支持让 Lutris 自己把环境变量或 wrapper 注入嵌套会话。必须先从 Lutris 退出，再在宝石棱镜里手动启动命令。游戏 id 可用 `lutris --list-games` 查看。

### 2.3 已有游戏窗口

游戏已经在运行时使用。先选窗口类型：

- **X11 窗口**：窗口列表会显示可捕获的 X11/XWayland 顶层窗口。点选目标窗口，再点“开始超分”。窗口可以窗口化，也可以全屏。
- **Wayland 全屏窗口**：点“开始超分”后会弹出系统选择器。此路径**只支持全屏的原生 Wayland 窗口**，因为它不转发输入，而是让鼠标直接穿透到画面下方的游戏。窗口化的原生 Wayland 游戏请改用嵌套启动。

窗口列表会自动刷新；“设置”里只能改刷新间隔，没有手动刷新按钮。

## 3. 开始、暂停、停止

| 按钮 | 行为 |
|---|---|
| **开始超分** | 按当前启动方式建立会话。 |
| **暂停超分 / 继续超分** | 暂停显示，不结束进程。X11/portal 模式隐藏覆盖层；嵌套模式切回游戏原窗口。再点一次恢复超分画面。 |
| **停止超分** | 真正结束会话。嵌套模式会结束本次命令启动的游戏/启动器；已有窗口模式只关闭覆盖层，不关闭游戏。 |

热键 `Alt+Shift+A` 也可显示/隐藏超分画面；在嵌套模式下等同暂停/继续。v1.0 不支持修改热键。

## 4. 托盘

默认启用。托盘可用时菜单包含：显示设置窗口、开始超分、停止超分、显示/隐藏覆盖层、退出。

- “显示/隐藏覆盖层”只对已有窗口模式有效；嵌套模式请用“暂停超分”。
- “开始超分”使用当前界面里选中的启动方式、显示器和命令。
- 托盘不可用（例如缺少 StatusNotifierItem/AppIndicator 支持）时，程序仍可正常使用，但关闭窗口只能直接退出。

“设置 → 关闭窗口行为”可选“直接退出”或“最小化到托盘”。选择托盘但托盘不可用时，会回退为直接退出。

## 5. 弹窗、最小化与焦点

- 游戏弹出确认框/设置框时，会创建额外的宿主窗口，原游戏画面保留。
- 点宿主窗口标题栏的关闭按钮，会把关闭请求转发给嵌套里的对应窗口，而不是结束整个会话。
- X11 游戏按 Esc 自我最小化时，宝石棱镜会避免闪黑，但宿主窗口不会跟着最小化；需要从任务栏恢复。
- 原生 Wayland 的自我最小化无法从客户端恢复，需要用户从任务栏恢复。
- “跟随焦点”开启时，切到别的程序可能收起覆盖层；这是预期行为。

## 6. 多显示器

- 每个会话只覆盖选中的一块屏。
- 嵌套会话按所选屏幕的物理分辨率和刷新率创建虚拟桌面；运行中不会跟随显示器热插拔/分辨率变化，换屏请重新开始会话。
- 不做跨屏连续拼接；多块屏各自独立超分。

## 7. 设置页

| 选项 | 说明 |
|---|---|
| 显示/隐藏热键 | 固定 `Alt+Shift+A`，只读。 |
| 重复打开时的行为 | 再开一个 GUI 时“弹窗提示”或“激活已有窗口”。CLI 第二实例始终报错。 |
| 关闭窗口行为 | 直接退出 / 最小化到托盘。 |
| 托盘 | 启用或禁用托盘。 |
| 窗口列表刷新间隔 | 250–5000 毫秒，窗口列表始终自动刷新。 |
| 日志位置 | 默认路径只读显示；可打开日志目录。 |
| 恢复默认 | 恢复界面默认值，点“保存设置”后才写入。 |

## 8. 日志与诊断

- “日志”页显示本次运行日志；“打开日志目录”打开 `~/.local/share/GemPrismUpscaler/`。
- “导出诊断包”生成一个 zip，包含环境、脱敏后的配置、日志尾部、最近错误和嵌套运行状态。日志里仍可能包含窗口标题，分享前请先检查。
- 命令行对应命令：`--diagnose`。

更多排障见[常见问题](troubleshooting.md)。
